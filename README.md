# QUTTY — документация

Быстрый, безопасный, открытый мессенджер. Работает без VPN.

---

## Как начать пользоваться

1. Перейти на сайт: https://qutty-messenger.surge.sh
2. Выбрать способ входа:
   - Email — код придёт на почту
   - Telegram — код придёт от бота @QuttyCodeBot
3. Ввести код и войти

---

## APK для Android

Скачать последнюю версию APK можно в Telegram-канале: https://t.me/qutty_news

---

## Вход через Telegram бота

1. Написать боту @QuttyCodeBot
2. Нажать кнопку "Поделиться номером"
3. Получить код
4. Ввести код на сайте
